## What is an SOP?
A **Standard Operating Procedure** = the one right way to do a recurring task, written so anyone can follow it and hit the [[The Next Level Standard|standard]]. Use [[SOP Template]] to create each one.

## The rule that builds this section
> When any task is done twice, or anyone asks how to do something twice — **it becomes an SOP.** Don't answer the question; write the answer down and send the link. That habit, repeated, is what lets Next Level scale.
