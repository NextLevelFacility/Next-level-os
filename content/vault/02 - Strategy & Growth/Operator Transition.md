# Operator Transition

> [!nl] The goal
> Every location runs on systems under one accountable Operator. Gabriel audits the data and meets the Operator; he does not run the floor.

## The four phases
1. **Build and launch** — Gabriel hands-on. Gate: doors open, first members paying.
2. **Grow** — Gabriel leads growth, recruits the Operator. Gate: revenue target hit, Operator hired.
3. **Hand off** — Operator runs daily ops, Gabriel checks weekly. Gate: Operator on target for a set number of months without Gabriel stepping in.
4. **Oversight** — Gabriel audits [[Key Metrics]] and meets the Operator on a set rhythm.
